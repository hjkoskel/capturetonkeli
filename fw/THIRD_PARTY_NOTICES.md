The **web UI** (`index.html`, `js/`, `css/`), the **Go library and ctpbench
sources** (`ctp/`, `cmd/`, `conformance/`) and the **firmware sources**
(`firmware/`) contain no third-party code. Go programs link only the Go
standard library (BSD-3-Clause, Copyright The Go Authors).

The FPV viewer (`js/hxfec.js`, `js/hxfpv.js`, docs/12) implements the
over-the-air format of hx-esp32-cam-fpv (MIT, Copyright 2021 jeanleflambeur
and contributors) for interoperability; no code was copied. The test fixtures
`test/js/fixtures/hxfpv-*.json` are output data generated with that project's
C sources.

The OpenHD receiver (`js/openhd.js`, `js/ohd*.js`, `js/rtp.js`,
`js/mavlink*.js`, docs/13) implements the over-the-air format of OpenHD and
its wifibroadcast library (GPL-3.0, OpenHD contributors) for
interoperability, written from the specification in docs/13; no code was
copied. The cryptographic primitives are written from their published
descriptions (Salsa20/ChaCha20/Poly1305 as used by libsodium, RFC 7748,
RFC 7693, RFC 9106). Interoperability constants taken over: the bind-phrase
salts, the keys derived from the default phrase "openhd", the HT40 side per
channel, and in `js/mavlink-crc.js` the per-message CRC_EXTRA and length
values of the MAVLink C headers generated by OpenHD/mavlink-headers (MAVLink
generated code: MIT licence). The test fixtures `test/js/fixtures/ohd-*.json`
are output data generated with libsodium, OpenHD's wifibroadcast and MAVLink
code and GStreamer; `docs/13-assets/gen_vectors.cpp` (our code) links
OpenHD's sources at build time, which are not part of this repository.
